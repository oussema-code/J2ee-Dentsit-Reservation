# J2EE Dental Clinic Appointment & Reservation System

An enterprise web application built using Java Jakarta EE, Maven, and HTML/CSS/JavaScript for dental clinic appointment scheduling and patient management.

## Features
- Patient online booking portal
- - Dentist schedule conflict prevention
  - - Patient record management
   
    - ## Build & Setup
    - Run the following command to build the project:
    - ```bash
      mvn clean package
      ```
